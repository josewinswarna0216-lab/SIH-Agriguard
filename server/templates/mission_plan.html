Autonomous Inspection Scout Drone — Mission Concept

Daily Inspection Flight Plan

A lightweight, low-cost scout drone built for the one job heavy spraying drones aren't: flying low and slow enough for reliable leaf-level disease detection. It complements a farm's existing agricultural drones rather than replacing them — grid survey, a close 360° scan at each tree, a low-altitude soil-moisture pass, then an unassisted return to base.

What's real vs. concept: disease detection, irrigation logic, live dashboard, and the daily PDF report run on real captured images and sensor data today. This flight path is the planned mission for the physical airframe — the next build phase.
Why a scout drone, not a replacement: a farm's existing agricultural drones fly high and fast to cover ground efficiently for spraying — not built for the slow, close, low-altitude passes reliable leaf-level detection needs. This scout drone is small, light, and cheap enough to fly alongside them, doing the one job they structurally can't.
